# APN の認証（CHAP/PAP）試験版 ― comma 3X をお持ちの方へ（SSH は要りません）

ユーザー名とパスワードを入れないとデータ通信ができない SIM（CHAP/PAP の認証が要る SIM）を、openpilot で使えるようにする試験版です。いまの openpilot には、この設定がありません。

試していただきたいのは、**comma 3X に、認証が要る SIM を挿している方**です。comma four でも動きます。

操作は、すべて端末の画面だけでできます。結果は、端末に出る「モデムの状態」の画面を**スマホで撮って**送ってください。

> この版は試験用で、comma の公式なソフトではありません。運転中には操作せず、必ず駐車中に試してください。
>
> **確認の状況**：comma four では実機で一通り確かめました。comma 3X の画面は、Mac で描いて確かめただけで、まだ 3X の実機では動かしていません（あなたが最初の一人になるかもしれません）。おかしな動きがあれば、その画面を撮って送ってください。

---

## 1. 先に読んでください

- **入れるには、端末をいったん初期化します。** 設定、Wi-Fi、端末に残っている録画は消えます。残したい録画は、先に comma connect などで取り出してください。
- **Wi-Fi が要ります。** 最初に約 1 GB を取ってきます。WPA2 でつながる Wi-Fi を用意してください（この版は WPA3 だけの Wi-Fi にはつながりません）。認証が要る SIM は、設定が済むまで携帯回線が使えないためです。
- **正式版 0.11.1 を使っている方は、AGNOS（端末の OS）も 19.9 に更新されます。** 自動で進みます。途中で電源を切らないでください。
- **設定 → ソフトウェア の「対象ブランチ」は触らないでください。** この試験版では、試験と関係のないブランチ（端末の OS を入れ替えるものを含む）が一覧に出ます。
- 中身は comma の 0.11.2（テスト版、release-tizi-staging）と同じで、モデムと設定画面の部分だけが違います。運転支援の部分には手を入れていません。
- 試験の値は、端末の中のファイルに保存します。ほかの設定と違い、comma のサーバーには送られません。ただし、**終わったら必ず「6. 片付け」をしてください。** モデムは、入れた認証情報を電源を切っても覚えています。

### 写真を撮るときの注意
- 撮るのは「**モデムの状態**」（英語表示では Modem Status）の画面だけにしてください。この画面には、IMEI、SIM の番号（ICCID）、電話番号、IP アドレス、基地局の番号、ユーザー名、パスワードは出ません。
- 「APN」の行には、入れた APN がそのまま出ます。会社の APN など人に見せたくない場合は、そこを指で隠すか、送る前に塗りつぶしてください。
- 「デバイス」の設定画面には、端末のシリアルや Dongle ID が出ます。そこは撮らないでください。

---

## 2. 入れる前に、控えておくもの
1. いまのソフトの版：設定 → ソフトウェア の一番上に出ます。
2. いま使っている APN（設定 → ネットワーク → 詳細設定 → APN設定）。SIM の会社の案内に書いてある APN、ユーザー名、パスワード、認証方式（CHAP か PAP）も手元に用意してください。
3. Wi-Fi の名前とパスワード。

## 3. 入れ方（20〜40 分ほど）
1. 設定 → **ソフトウェア** → **アンインストール** を押す。確認の画面で、もう一度押す。
   - 再起動したあとの「消去しますか」という画面で、**確認を 2 回**押してください。何もしないまま 3 分たつか、キャンセルを押すと、消去せずに元のソフトのまま起動します。
2. 初期設定の画面で、Wi-Fi につなぐ。
3. ソフトの選択で「**カスタムソフトウェア**」を選び、次のとおりに入力する（大文字・小文字も同じに）：
   ```
   shunnag/apn-auth
   ```
4. 警告の画面が出たら、内容を読んで進める。ダウンロード（数分〜十数分）と、必要なら AGNOS の更新（再起動あり）が進みます。
5. 利用規約と使い方の説明が出たら、いつもどおり進める。ホーム画面が出たら完了です。
6. 設定 → ソフトウェア で、ブランチが `apn-auth` になっていることを見る。

## 4. 試す（段階 A → B → C）

どの段階も、最後に「モデムの状態」を開いて写真を撮ります。開き方：設定 → ネットワーク → 詳細設定 → 下のほうの「**モデムの状態**」の「表示」。画面の中身は英語です。1 枚に全部が入ります。
（comma four では、設定 → ネットワーク を右へ送った先の「**modem status**」→ view。上下に送って、2〜4 枚に分けて撮ってください）

画面の見かた（大事な行だけ）：
- `State`：CONNECTED ならつながっている。SEARCHING のままならつながっていない
- `Registration`：home（登録できた）／denied（拒否された）／searching（探している）
- `Auth`：入れた方式と、モデムに書けたか（`readback ok` なら書けた）
- `Data`：yes なら携帯回線でデータが流れている
- `PPP`：`up` ならつながっている。設定を変えた直後に「last retry」として 1 回分の失敗が出るのは正常です
- `CEER`：つながらなかった理由の番号（例：`"ESM",29` は「ユーザー認証の失敗」）

### 段階 A：認証なし（今までと同じ状態）― 必ず最初に
**飛ばさないでください。** 「認証なしではつながらず、認証を入れるとつながる」ことの証拠になります。

1. 詳細設定 → APN設定 で、SIM の会社の APN を入れる。**ユーザー名・パスワード・ログイン方法は、まだ入れない。**
2. 3 分待つ。
3. モデムの状態を開いて**写真 A** を撮る。

### 段階 B：認証を入れる
（comma four では、設定 → ネットワーク の「apn user name」「apn password」「apn auth」（押すたびに off → chap → pap）、片付けは「delete apn credentials」です）

1. 詳細設定 → **APNユーザー名** → 編集 → ユーザー名を入れる。
2. **APNパスワード** → 編集 → パスワードを入れる（入力中は伏せ字になります。右の目のマークで表示）。
3. **APNログイン方法** で、SIM の会社の案内のとおり **CHAP** か **PAP** を押す（分からなければ CHAP）。
   - 押すと、携帯回線が 1 回つなぎ直します（10〜20 秒）。
4. 3 分待つ。モデムの状態を開いて**写真 B** を撮る。
5. つながったかどうかは、モデムの状態の「Data」が yes になっているかで分かります。

### 段階 C：再起動しても保たれるか
1. 設定 → デバイス → 再起動。
2. 起動してから 3 分待つ。モデムの状態を開いて**写真 C** を撮る。

### （できれば）段階 D：わざと間違ったパスワード
SIM の会社がパスワードを確かめているかどうかが分かります。
1. APNパスワード を、1 文字変えたものにする。
2. 3 分待つ。モデムの状態を開いて**写真 D** を撮る。
3. 正しいパスワードに戻す。

## 5. 送るもの
写真 A〜C（あれば D、E）と、次の内容を、**募集を投稿した人への Discord の DM で**送ってください。
**写真はチャンネルやスレッドには貼らないでください。** 個人を特定できる情報は出ない画面ですが、念のためです。

```
機種：comma 3X / comma four
SIM の会社とプラン：（例：○○モバイル データ SIM）
認証方式：CHAP / PAP
入れる前のソフトの版：（例：0.11.1）
段階 A：つながった / つながらない
段階 B：つながった / つながらない（ログイン方法を押してから何分くらいか）
段階 C：つながった / つながらない
段階 D：（試した場合）
気づいたこと：
```

## 6. 片付け（必ず）
1. 詳細設定 → **APNログイン情報を削除** → はい。
   （または、APNログイン方法 で「オフ」→「保存済みのAPNユーザー名とパスワードも削除しますか？」で はい）
2. モデムの状態を開き、「Auth」が `none` で、`readback ok` になっていることを見る（モデムからも消えた印です）。できれば**写真 E** も送ってください。
3. 元のソフトに戻す：設定 → ソフトウェア → アンインストール → 初期設定 → カスタムソフトウェアで、次のどちらかを入れる：
   - `openpilot-test.comma.ai`（comma の 0.11.2 テスト版。この試験版と同じ AGNOS なので、安全に戻れます）
   - 正式版 `openpilot.comma.ai` は、**正式版が 0.11.2 になってから**にしてください。0.11.1 は AGNOS 19.9 の上では起動を繰り返すことがあると、comma が報告しています（openpilot #39063）。
   - 戻せなくなったときの最後の手段は、comma 公式の https://flash.comma.ai です。

**注意**：片付けの 1 をせずにアンインストールや SIM の入れ替えをすると、モデムに認証情報が残ります（電源を切っても消えません）。忘れた場合は、もう一度この試験版を入れて 1 をしてください。

## よくある質問
- **Q. 端末のビルドが始まって終わらない／「failed to build」と出た**：この版はビルド済みなので、ビルドは走らないはずです。出た場合は、その画面を撮って送ってください。アンインストールで元に戻せます。
- **Q. 詳細設定に APN の行が出ない**：comma prime のフル（comma の SIM）を使っている端末では出ません。この試験は、自分の SIM を挿した端末向けです。
- **Q. 送ったものはどう使われますか**：commaai/openpilot へ、APN 認証の対応を提案するときの証拠に使います（写真はそのまま公開しません。数字と結果を文章で引用します）。
